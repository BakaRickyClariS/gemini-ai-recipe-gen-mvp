# 📊 AI Token 成本分析報告

> 最後更新：2026-01-05

本文檔分析 Recipe API 中所有 AI 服務的 Token 使用量與成本估算。

---

## 🎯 各 API Token 使用量

### 1. AI 食譜生成 (`POST /api/v1/ai/recipe`)

| 類別              | Token 數 (估算)  | 說明                              |
| ----------------- | ---------------- | --------------------------------- |
| **System Prompt** | ~1,800-2,000     | 包含完整指令、JSON 結構、安全規則 |
| **使用者輸入**    | ~20-100          | 依使用者 prompt 長度而定          |
| **AI 輸出**       | ~1,500-3,500     | 依食譜數量 (2 道約 2,500 tokens)  |
| **單次總計**      | **~3,300-5,600** | Input + Output                    |

**Generation Config:**

- `maxOutputTokens: 4096`
- `temperature: 0.7`

---

### 2. AI 圖片生成 (`imageGenerationService.ts`)

| 類別         | Token 數 (估算) | 說明                            |
| ------------ | --------------- | ------------------------------- |
| **Prompt**   | ~80-120         | 中文描述 + 風格設定             |
| **AI 輸出**  | 圖片資料        | 回傳 Base64 圖片 (非文字 Token) |
| **單次總計** | **~100-150**    | 文字 Token（圖片生成另計）      |

**模型:** `gemini-2.0-flash-exp-image-generation`

---

### 3. 單一食材辨識 (`POST /api/v1/ai/analyze-image`)

| 類別              | Token 數 (估算)  | 說明                           |
| ----------------- | ---------------- | ------------------------------ |
| **System Prompt** | ~700-800         | JSON 結構定義、分類說明        |
| **圖片輸入**      | ~256-1,024       | Gemini 視覺 token (依圖片大小) |
| **AI 輸出**       | ~200-400         | 單一食材 JSON 結果             |
| **單次總計**      | **~1,150-2,200** | Input + Output                 |

---

### 4. 多食材辨識 (`POST /api/v1/ai/analyze-image/multiple`)

| 類別              | Token 數 (估算)  | 說明                                 |
| ----------------- | ---------------- | ------------------------------------ |
| **System Prompt** | ~1,600-1,800     | 包含情境判斷、7 大分類、完整欄位說明 |
| **圖片輸入**      | ~256-1,024       | Gemini 視覺 token                    |
| **AI 輸出**       | ~800-2,500       | 依食材數量 (10 個約 2,000 tokens)    |
| **單次總計**      | **~2,650-5,300** | Input + Output                       |

## 🔄 成本優化策略

### 1. Context Caching（上下文快取）

- **效果**：輸入成本最高可降低 **90%**
- **適用情境**：重複使用相同的 System Prompt
- **注意**：需額外儲存費用

### 2. Batch Processing（批次處理）

- **效果**：所有 token 成本降低 **50%**
- **適用情境**：非即時性的大量請求
- **限制**：延遲較高，不適合即時 API

### 3. 選用 Flash-Lite 模型

| 模型                  | 單次食譜成本 | 節省幅度     |
| --------------------- | ------------ | ------------ |
| Gemini 2.5 Flash      | $0.00685     | 基準         |
| Gemini 2.5 Flash-Lite | $0.00124     | **節省 82%** |

### 4. 多 API Key 輪換（免費方案最大化）

本專案已實作多 API Key Fallback 機制：

- 配置 3 個 API Key = **4,500 次/日** 免費請求
- 配置 10 個 API Key = **15,000 次/日** 免費請求
